## 이후 작업 기록 방법

- [TEMPLATE.md](TEMPLATE.md)를 사용합니다. 큰 작업은 작업별 파일, 작은 수정은 같은 날짜의 작업 기록으로 묶습니다.
- 파일명은 `YYYY-MM-DD-작업명.md`를 기본으로 합니다. 같은 날 같은 작업명이 있으면 구분자를 추가합니다.
- 작업 종료 시 요청·대상 링크·변경 내용·근거·실제 검증 범위·남은 작업을 기록하고 이 목차에 링크를 추가합니다.
- 작업 반영 상태와 검수 결과를 구분합니다. 문서 수정·Figma 반영·개발 구현·실제 동작 검증을 같은 완료로 기록하지 않습니다.
- 검수 결과는 확정 근거가 있는 범위만 기재합니다. 미확정 결과와 검토일·검토자 등 확인되지 않은 값은 빈칸으로 남깁니다. 필요한 질문과 미완료 사항은 별도 비고에 기록합니다.
- 작업일이 확인되지 않으면 날짜를 추측하지 않습니다. 소급 기록은 작성일과 실제 작업일을 구분합니다.
- 승인 범위가 바뀌면 이전 기록을 지우지 않고 후속 기록과 근거를 연결합니다. 비밀번호·토큰·개인정보는 기록하지 않습니다.

## 간단 기록

작은 수정은 기존 기록 파일에 아래 최소 항목을 남기고 목차를 연결합니다. 단순 검토 의견은 답변에 남길 수 있습니다.

- 요청·대상·범위와 적용 기준
- 직접 확인한 내용과 실제 변경
- 실제 검증 방법·범위·결과
- 미정·미확인·미검증·다음 작업

공통 원본·변수 또는 여러 화면에 영향을 주는 작업은 [상세 양식](TEMPLATE.md)을 사용합니다. 재개할 때는 마지막 결정·변경·검증·남은 작업을 읽고 현재 원본을 확인합니다.
