## 후속 Figma 적용 — 2026-11-10

- 사용자 요청으로 로그인/회원가입 페이지의 화면 프레임 67개에서 노드 ID와 공통 추적 번호 접미사를 제거했습니다.
- 같은 페이지에서 중복되는 화면명은 기존 섹션·레이어 순서에 따라 이름 뒤에 01·02 형식으로 번호를 붙였습니다. 예: 로그인 01~05, 회원가입 완료 01~04. 중복 없는 화면명에는 번호를 붙이지 않았습니다.
- 화면명이 동일한 경우도 의미를 추측해 바꾸지 않고 기존 화면명과 번호만 사용했습니다.
- 검증: 화면 프레임 이름 중복 0건. 편집 대상 외 3,127개 노드의 이름 불변 확인. 화면 내부 문구·디자인·컴포넌트·원본 ID 변경 없음. 이름만 변경해 화면 캡처 검수는 해당 없음.
- 대상: [로그인/회원가입](https://www.figma.com/design/1Qe6U3JD2oHDmofvcKr4ho/TLDS3.0?node-id=5029-45347). 화면설계서 페이지와 내부 레이어·섹션 이름은 변경하지 않았습니다.
