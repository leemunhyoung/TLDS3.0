# 사람용 시작 페이지와 업무 연결 통합

작업일: 2026-11-09

## 요청과 기준

사용자가 TLDS3.0 원본 수정을 요청했습니다. 디자인 규칙·수치·기존 결정·이력은 TLDS3.0을 기준으로 유지하고, Desing_guide에서는 템플릿·워크플로우 구성·사람용 진입점을 참고하도록 지정했습니다.

## 변경

- [사람용 시작 페이지](../index.html)와 [안내 원본](../index.md)을 추가했습니다.
- 루트와 Design 시작 안내에 공통 가이드·사람용 페이지·AI 업무 시작점을 연결했습니다.
- [요청별 업무 시작점](../workflows/AGENTS.md), [문서 지침](../docs/AGENTS.md), [스킬 선택 안내](../workflows/skills/AGENTS.md)를 추가했습니다.
- 기존 3종 업무 절차를 재사용하고, 개발 전달·공동 검수·작업 재개·간단 기록 경로를 보완했습니다.
- 공통 문서 자원은 Desing_guide에서 복사했습니다. [출처와 파일 해시](../docs/asset-sources.json)를 남겼으며 원본 커밋은 미확인입니다.

## 검증과 적용 범위

반영 전 검증에서 내부 링크·자원 연결 183개, 문서 내 위치 연결 11개를 확인했습니다. 안내 원본과 HTML의 본문·링크가 일치했습니다. 기존 디자인 기준 6개와 과거 이력 2개 파일은 SHA-256으로 원본 보존을 확인했습니다. 기존 규칙·업무 절차·상세 양식·팀 인계·검수표의 본문은 유지하고 연결 안내를 추가했습니다. 시작 안내와 기록 목차는 새 경로에 맞춰 정리했습니다.

브라우저의 로컬 파일 열기 제한으로 실제 화면 배치·모바일 렌더링·키보드 동작은 미검증입니다. CSS·JS 경로와 HTML 구조의 정적 확인 결과와 구분합니다. TLDS3.0 원본에 22개 파일을 반영한 뒤 파일 해시·내부 연결 183개·문서 내 위치 연결 11개·안내 원본/HTML 일치를 다시 확인했고 오류가 없었습니다. 기존 기준·과거 이력 8개 파일의 원본 보존과 common.js 구문 검사도 통과했습니다. Git 변경 목록을 확인했으며 커밋·외부 게시는 수행하지 않았습니다.

Figma 편집·프론트 원본 조회·Storybook 비교·실제 앱 검증·스킬 설치는 수행하지 않았습니다. 기존 문서의 과거 검증·승인을 이번 검증으로 바꾸지 않았습니다.

## 다음 작업

실제 화면 업무에서 공통·파트 지침과 요청별 경로를 사용하고, 필요한 개발 원본·Figma 접근 및 공동 검수는 해당 업무 범위에서 확인합니다. 사용자 검수 결과는 아직 기록하지 않습니다.
