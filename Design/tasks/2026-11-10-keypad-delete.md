# 숫자패드 선형 지우기 아이콘 적용 — 2026-11-10

- 사용자와 첨부 지우기 아이콘의 선형 대응인 lucide/delete를 확인한 뒤 숫자패드에 적용했습니다.
- 대상: 로그인/회원가입의 간편비밀번호 입력(5032:125), 설정(5032:2470), 재입력(5032:2557). 기존 마지막 줄은 취소·0 두 버튼으로 구성되어 있어 오른쪽 빈 자리에 한 글자 지우기를 추가했습니다.
- 아이콘 원본: Lucide Icons / lucide/delete, 128:902. 버튼은 기존 Icon Button / Ghost / Large / Default 원본의 인스턴스입니다. 생성 버튼 ID: 5231:2475, 5231:2480, 5231:2484.
- 버튼 영역 103×48px, 아이콘 실제 표시 16×16px, 중앙 정렬(x43.5/y16). 색상은 기존 foreground 변수에 연결했습니다. 마지막 행 너비 214→325px이며 위 숫자 행과 동일합니다. 기존 숫자·취소·문구·화면 이름·공통 원본은 변경하지 않았습니다.
- 구조 확인: 세 화면의 버튼 크기·아이콘 원본 연결·동일한 위치를 확인했습니다. 입력 화면을 1배율 캡처하여 마지막 줄의 지우기 아이콘 표시와 정렬을 확인했습니다. 설정·재입력은 동일한 구조와 수치로 확인했습니다.
