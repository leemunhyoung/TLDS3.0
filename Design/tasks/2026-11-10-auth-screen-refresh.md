- 대상: 로그인/회원가입 페이지 5029:45347의 기존 01~07 및09 섹션 화면64개, 08 알럿 메시지 정리 프레임6개. 기존 화면 루트 ID와 이름·위치 유지. 컴포넌트 원본·공유 변수 값·다른 페이지 수정 없음.

## 반영

- 기존 화면13개는 대응하는 새 시안의 편집 가능한 레이어·컴포넌트 인스턴스를 복제해 내부 구성을 갱신. 루트 프레임 ID는 유지. 직접로그인 입력값·네트워크 오류 메시지·요청 중 Disabled 상태·비밀번호 재입력 제목 등 상태 차이를 보존.
- 나머지51개 화면: 상태바44px+Header48px, 좌우20px 및 상단20px, 주요 묶음 간28px. Field 내부8px. 약관9개 항목은 별도 Auto Layout에12px 간격. 기존 입력 항목·동의 항목·문구 유지.
- 탭은 Underline 형태40px, 선택 상태와 라벨 유지. 입력창은 기준 시안과 같은 Large48px. 기본 화면 최소820px이며 긴 폼은 내용을 잘라내지 않도록 프레임 높이를 확장.
- 가입 방식 선택3개 화면의 소셜 버튼10개를 현재 Social Login Button 원본에 연결. 카카오로 계속하기·네이버로 계속하기·구글로 계속하기·애플로 계속하기 문구 유지.
- 알럿 카드와 화면 오버레이 총71개 내부를 기준 시안처럼 정리:335px 폭, 내용16px 여백, 버튼 영역16px 여백, 버튼48px 및 두 버튼 가로 배치. 메시지·버튼 수·문구 유지.
- 기존 하단 안전영역은 기준 시안의 Home Indicator 구성을 사용. 원본 시안에 포함된 숨김 하단 메뉴·이전 작업 레이어도 복제된 경우가 있어 전체 텍스트 목록에는 숨김 문구가 나타날 수 있으나 화면에는 표시되지 않음.

## 실제 검증

- 수정 전70개 프레임의 문구를 기록하고 최종 문구 대조. 기준 시안에 직접 대응한13개를 제외한57개(일반 화면51+알럿 보드6)에서 기존 문구 누락0건.
- 전체70개 루트 프레임에서 실제 표시 텍스트의 좌우/하단 프레임 초과0건. 표시 중인 모든 Tab 높이40px, Input 높이48px 확인.
- 직접로그인·입력 알럿·키패드·내외국인·재로그인·SNS 가입·본인확인·아이디찾기·인증번호 상태·새 비밀번호·ID/PW·약관·추가정보·어린이·완료·가입방식·네트워크 오류 등 대표 화면을 캡처해 비교. 약관 간격 및1/2버튼 알럿 수정 후 재검수.
- 네이버 PNG는 일부 모음 캡처에서 로고가 늦게 표시되어 단독 버튼을 다시 캡처했고 정상 표시를 확인.
- 대표 캡처 검수이며 모든 화면의 모든 상태를 개별 캡처한 것은 아님. 앱 구현·프로토타입 동작·키보드 및 실기기 스크롤은 검증하지 않음. 문구/정책/설계서 대비 최종 검토는 사용자 예정.
