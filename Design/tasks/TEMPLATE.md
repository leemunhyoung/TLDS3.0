## 11. AI 작업 결과 양식

```text
작업명·ID / 사용한 기준 버전:
결과 Figma 링크:
변경 내용:
기준 시안 대비 크기·내부 여백·간격·정렬·Hug/Fill 및 상태별 비교 결과:
기준/결과 노드·비교 캡처 위치:
추가 컴포넌트의 용도·상태·구성·연결 변수·미연결 값:
프론트 개발자 코드·시멘틱 토큰 매핑 인계 사항:
영향받은 변수·컴포넌트·화면:
검수 결과: 통과 / 문제 있음 / 확인 불가
검수 방법과 확인한 범위(공통 검수표 적용):
문구 누락·추가 대조 결과:
실제 폰트·Family/Weight/Size 변수 연결 결과:
폴드 양방향 전환 검수(Figma/실제 앱 구분, 해당 시):
컬러 기준표·스타일·가이드 동기화 및 Dark 보존 검수:
완료 항목:
미완료 항목·노드 링크·사유:
임시 적용·승인 근거:
미확정 사항·추가 제안:
갱신해야 할 기준 자료:
결정 상태: 확정 / 승인된 예외 / 미확정 (근거·범위 포함):
다음 담당자·다음 작업·공유한 공통 변경:
```

검수하지 않은 항목은 통과로 표시하지 않는다. 편집 도구가 없으면 작업 계획 또는 수정 명세로 제출하고 Figma 수정 완료로 보고하지 않는다.
