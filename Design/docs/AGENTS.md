# 디자인 문서 편집 지침

## 기준과 변경 범위

디자인의 규칙·수치·변수·정책·승인 상태·이력은 TLDS3.0을 기준으로 유지합니다. 문서의 표현이나 구조를 정리하면서 의미를 바꾸지 않습니다. Desing_guide는 템플릿·워크플로우 구성·사람용 진입점의 참고 자료입니다.

## 작성과 연결

- [공통 문서 운영](https://idtloungepmo.github.io/lounge3.0_guide/project/documentation.md)과 [공용 글쓰기 안내](https://idtloungepmo.github.io/lounge3.0_guide/skills/guides/korean-work-writing/SKILL.md)의 필요한 내용을 확인합니다. 안내 본문은 차분한 ‘합니다’체로 쓰고 코드·파일명·인용·기존 기록의 식별자를 보존합니다.
- [사람용 안내 원본](../index.md)을 바꾸면 [HTML](../index.html)도 맞춥니다. 상세 디자인 기준은 기존 문서로 연결하고 시작 페이지에 별도 확정본으로 복제하지 않습니다.
- 새로운 문서는 [업무 시작점](../workflows/AGENTS.md)과 사람용 안내에서 필요한 경우 연결합니다. assets/에는 CSS·JS·이미지 등 자원만 둡니다.
- 기존 docs/·workflows/·tasks/ 경로를 재사용합니다. 공통의 docs/guides·docs/workflow 구조와는 위치가 다르며, 같은 역할의 폴더를 추가로 병행하지 않습니다.
- 과거 기록은 당시 상태로 보존합니다. 새 결정은 적용 범위와 근거, 이전 기준과의 관계를 남깁니다.

## 검증

내용 원본과 HTML의 문구·표·링크를 대조하고 내부 링크·앵커·CSS·JS 경로를 확인합니다. 화면을 바꾸면 가능한 환경에서 데스크톱·모바일 배치와 가로 넘침·표 스크롤·키보드 이동을 확인합니다. 실제 확인하지 못한 환경은 미검증으로 기록합니다.

문서만 편집한 결과를 Figma 반영·개발 구현·실제 앱 검증 완료로 표시하지 않습니다. 변경과 검증 범위는 [작업 기록](../tasks/README.md)에 남깁니다.

## 템플릿과 공통 자원 관리

사람용 시작 페이지의 구성과 assets/의 세 CSS·common.js는 사용자 제공 Desing_guide의 로컬 파일을 참고·복사했습니다. 공통 원본의 기준 커밋은 미확인입니다. 복사 시점의 SHA-256과 원본 위치는 [자원 출처](asset-sources.json)에 기록합니다. 이 색상·글꼴은 문서 표시용이며 서비스 UI 토큰을 변경하지 않습니다.

자동 동기화되지 않습니다. 갱신할 때 공통 가이드 원본·로컬 참고본의 차이를 비교하고 기준 커밋을 확인할 수 있으면 기록합니다. 필요한 자원만 갱신한 뒤 시작 페이지를 확인합니다. GitHub 파일 보기 주소를 CSS·JS 주소로 사용하지 않습니다.
