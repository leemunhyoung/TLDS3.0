# 디자인 작업 공통 검수표

모든 작업 A/B/C에 적용한다. 확인한 범위와 증거를 작업 결과에 남긴다. 해당 없음에는 이유를 적는다. 통과하지 않은 항목을 완료로 표시하지 않는다.

## 시작 전

- [ ] 소스와 결과의 Figma 링크·페이지·노드 ID·기준일을 확인했다.
- [ ] 허용 범위와 읽기 전용 대상을 구분했다.
- [ ] 지정 글꼴과 필요한 굵기를 AI 연결 환경에서 실제로 로드했다.
- [ ] 기존 컴포넌트·상태·변수 연결을 확인했다.
- [ ] 설계서 누락·충돌과 승인된 예외를 기록했다.

## 문구와 구성

- [ ] 소스 화면 ID와 결과 프레임이 대응된다.
- [ ] 제목·본문·라벨·버튼·탭·플레이스홀더·예시값·마스킹·날짜·타이머를 원문과 대조했다.
- [ ] 임의로 추가하거나 변경한 문구가 없다. 승인된 변경에는 근거가 있다.
- [ ] 문구를 포함한 필수 정보·기능·상태가 누락되지 않았다.
- [ ] 동의 항목 수와 의미를 유지했다. 안내문이 추가 동의로 바뀌지 않았다.
- [ ] 공통 화면 재사용과 소스 누락은 확인된 근거·적용 범위와 함께 기록했다.

## 시스템 연결과 화면

- [ ] 실제 적용된 서체와 굵기가 기준과 일치한다.
- [ ] 새 텍스트도 기존 Family·Weight·Size 등 해당 변수에 연결되어 있다.
- [ ] 직접 지정한 값, 혼합 스타일의 누락 구간, 끊어진 별칭을 확인했다.
- [ ] 기존 인스턴스·Variant·역할·동작을 유지했다.
- [ ] 변수 구조와 Light/Dark 모드를 보존했다. 현재 Light 작업을 이유로 Dark를 삭제하지 않았다.
- [ ] 대상 폭·스크롤·줄바꿈·잘림·겹침·알럿과 배경을 확인했다.
- [ ] 구조 확인과 실제 화면 캡처를 함께 확인했다.
- [ ] 보호 대상 페이지가 수정되지 않았다.

## 결과 보고

- [ ] 결과 링크와 영향받은 화면·컴포넌트·변수를 기록했다.
- [ ] 완료·미완료·임시 적용을 구분했다.
- [ ] 검수 범위·방법·불일치·확인 불가 사유를 기록했다.
- [ ] 미해결 항목의 위치·원문·질문과 다음 조치를 남겼다.

문구 검수는 추가된 표현뿐 아니라 빠진 표현도 확인한다. 텍스트의 존재만 확인하지 말고 화면에서 실제 보이는지, 올바른 요소에 배치되었는지도 확인한다.

## 폴드폰 대응 대상 작업

상세 기준: [폴드폰 대응](foldable.md). 대상이 아니면 그 이유와 기존 반응형 적용 범위를 기록한다.

- [ ] 적용 예상 페이지(제휴카드 페이지·마이페이지·사용처 페이지)와 실제 작업 범위를 확인했다.
- [ ] 동일 데이터·기능을 유지하고 신규 백엔드 기능을 전제로 하지 않았다.
- [ ] 접힌 상태는 현재 APP 레이아웃과 반응형 규칙을 적용한다.
- [ ] 사용처 페이지의 좌측 2뎁스 펼침·선택 표시·긴 항목을 고려했다.
- [ ] 제휴카드의 좌측 썸네일 선택과 우측 이용권·혜택이 대응한다.
- [ ] 카드가 없을 때 좌측 카드 모양 박스 중앙 + 버튼이 기존 등록 절차로 연결된다.
- [ ] 접기·펼치기 양방향으로 보고 있던 콘텐츠와 읽던 위치를 유지한다.
- [ ] 선택 카테고리·메뉴 펼침·선택 카드·입력 상태를 유지하며 상단 이동·선택 초기화·재진입이 없다.
- [ ] 스크롤 숫자 일치뿐 아니라 동일 콘텐츠가 보이는지 확인했다.
- [ ] Figma 배치 검수와 실제 앱 상태 유지 검증 결과를 구분했다.
- [ ] 전환 너비·영역 크기·스크롤 등 미확정 사항과 검증 환경을 기록했다.
