## 4. 컴포넌트 목차

한 페이지의 알파벳순 정리는 유지한다. AI가 대상을 찾을 수 있도록 아래 목차를 만든다. 실제 Figma를 AI가 읽을 수 있다면 목록 추출을 맡기고 담당자가 검토해도 된다.

| 컴포넌트 이름 | 구역/원본 노드 링크 | 속성·상태 확인 | 사용 여부 | 수정 상태 | 비고 |
|---|---|---|---|---|---|
| [입력] | [입력] | 미확인/확인 | 미정/사용/미사용 | 미수정/수정 중/검토 중/확정 | [입력] |
