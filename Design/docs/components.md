## 표기와 갱신 기준

- 목차 표기 Input OTP, Kbd, Scroll Area의 Figma 프레임 이름은 각각 Input OPT, KPD, Scroll-area다. 탐색을 위해 목차 표기만 정리했으며 실제 Figma 이름은 변경하지 않았다.
- Toggle과 Toggle Group은 현재 같은 구역에 있으므로 Toggle & Toggle Group 한 행으로 기록했다.
- 실제 사용이 확인되면 사용 여부를 갱신하고, 메인시안 반영 진행에 따라 수정 상태를 기록한다. 필요한 근거와 예외는 비고에 남긴다.
- 사용 여부와 수정 상태는 별개다. 상태값은 사용 여부: 미정/사용/미사용, 수정 상태: 미수정/수정 중/검토 중/확정으로 관리한다.
- 컴포넌트가 추가·이동되면 이름과 링크를 갱신한다. 수정 상태를 확정하기 전에 속성·상태를 검수한다.
- 미사용 판정 시 중첩 컴포넌트·다른 원본 내부 사용·다른 파일의 라이브러리 사용도 확인한다. 확인 불가능한 범위는 미확인으로 남긴다.
