# 디자인 업무 스킬 선택과 연결

[업무 시작점](../AGENTS.md)에서 이번 요청의 경로를 선택합니다. 기존 디자인 규칙과 원본·검수표가 기준입니다. 스킬은 필요한 작업 방법을 보완합니다.

| 필요한 작업 | 참고 가이드에 제시된 원본 후보 | 사용 조건 |
| --- | --- | --- |
| 모호한 요구·판단 정리 | grill-with-docs | 실제 질문이 있을 때 원본과 하위 지침을 확인합니다. |
| 합의한 내용의 명세화 | to-spec | 합의와 실제 기록 위치가 있을 때 선택합니다. |
| 큰 업무 분할 | to-tickets | 작업별 입력·선행 조건·검수 단위를 나눌 필요가 있을 때 선택합니다. |

후보 출처는 [맷 포코크 원본](https://github.com/mattpocock/skills)입니다. 위 표는 Desing_guide의 선택 안내를 참고한 것으로, 이번 통합에서는 원본 버전·하위 지침·설치·등록·실행을 확인하지 않았습니다. 사용 시 원본의 현재 내용과 도구 지원을 확인합니다. 기본 문서로 가능한 작업은 이어갑니다. 코드 구현·테스트 스킬은 코드 업무가 있을 때 선택합니다.

## 연결 정보

연결한 경우에만 스킬명·원본 URL·기준 버전·실제 위치·호출 방법·사용 조건·확인 결과를 기록합니다. 개인 환경의 설정과 저장소 공통 기준은 구분합니다. 현재 저장소에 이 안내를 추가한 것은 스킬 설치를 의미하지 않습니다.

새 파트 스킬은 반복되는 디자인팀 고유 업무가 확인될 때 필요한 범위에서 추가합니다. 기존 스킬로 충분하면 재작성하지 않습니다. 설치 명령은 사용자 요청과 실제 환경에 맞춰 선택하며 안내문만 보고 자동 실행하지 않습니다.
