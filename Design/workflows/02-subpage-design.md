# 02-subpage-design

먼저 [공통 규칙](../AGENTS.md)과 [디자인 시스템 기준](../docs/design-system.md)을 읽는다.

## 8. 작업 B — 서브페이지 디자인

### 입력

확정 디자인 시스템 버전, 화면설계서·화면 ID, 대상 채널·규격, 승인된 유사 화면, 정책·용어, 작업 위치.

### 수행

1. 화면설계서의 필수 정보·기능·상태를 목록화한다.
2. 기존 컴포넌트와 화면 패턴에 대응시킨다.
3. 디자인 시스템의 인스턴스를 우선 사용하여 화면을 제작한다.
4. 새로운 컴포넌트나 패턴이 필요하면 기존 것으로 해결할 수 없는 이유를 기록한다.
5. 설계서와 결과를 대조하고 관련 상태·스크롤·규격을 확인한다.

### 완료 조건

- 필수 정보와 기능이 누락되지 않는다.
- 기준 변수와 컴포넌트가 적용된다.
- 화면설계서에 없는 정책·기능을 확정사항으로 추가하지 않는다.
- 신규 제안과 미확정 사항이 구분된다.
- 해당 화면에서 사용한 컴포넌트를 목차에 기록한다.


작업 기록은 [양식](../tasks/TEMPLATE.md)을 사용한다.
