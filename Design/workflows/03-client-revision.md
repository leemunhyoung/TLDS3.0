# 03-client-revision

먼저 [공통 규칙](../AGENTS.md)과 [디자인 시스템 기준](../docs/design-system.md)을 읽는다.

## 9. 작업 C — 고객 수정사항 반영

### 입력

요청 원문, 요청 ID·일자, 대상 화면/노드, 반영하기로 확정된 범위, 현재 디자인 시스템·설계서 버전.

### 수행

1. 요청을 항목별로 나누고 완료 조건을 정리한다.
2. 화면 한 곳의 변경인지, 반복 패턴인지, 공통 컴포넌트·변수 변경인지 분류한다.
3. 공통 변경은 영향을 확인한다. 영향이 요청 범위를 벗어나면 먼저 확인한다.
4. 확정된 요청을 반영하고 해당 항목별로 검수한다.
5. 변경 전후, 영향받은 대상, 기준 문서 갱신 필요 여부를 기록한다.

### 완료 조건

- 확정된 요청이 반영되며 관계없는 부분을 임의로 바꾸지 않는다.
- 원본 수정에 따른 다른 인스턴스의 영향을 확인한다.
- 일회성 예외를 공통 기준으로 무단 확장하지 않는다.
- 고객 요청과 기존 기준의 충돌 및 미반영 사유가 기록된다.


작업 기록은 [양식](../tasks/TEMPLATE.md)을 사용한다.
