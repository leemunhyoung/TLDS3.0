# 더 라운지 3.0 디자인팀 AI 하네스

## 사람과 AI의 시작점

- [사람용 시작 페이지](index.html) · [안내 원본](index.md): 기준 문서와 업무를 찾습니다.
- [AI 작업 규칙](AGENTS.md) · [요청별 업무 시작점](workflows/AGENTS.md): 이번 작업에 필요한 경로를 선택합니다.
- [문서 편집 지침](docs/AGENTS.md) · [작업 기록](tasks/README.md): 문서 검증과 이력을 관리합니다.

디자인 내용은 TLDS3.0을 기준으로 유지합니다. Desing_guide는 템플릿·워크플로우 구성·사람용 진입점의 참고 자료입니다. 아래 v0.5는 과거 하네스 버전 기록이며, 이후 타이포·컴포넌트·이름 규칙과 작업 기록도 함께 확인합니다. 전체 컴포넌트 검수 여부는 별도입니다.

[프로젝트 공통 가이드](https://idtloungepmo.github.io/lounge3.0_guide/)와 파트 기준을 함께 확인합니다. 문서만 수정할 때는 문서 지침을 적용하고, 아래 Figma 기능·컬러·폰트 확인은 실제 디자인 작업에 적용합니다.

## AI와 신규 담당자 공통 안내

ChatGPT·Claude 등 어떤 AI를 사용해도 같은 디자인 기준을 적용합니다. [AI 공통 사용·팀 인계 안내](docs/ai-collaboration.md)에서 도구별 기능 확인, 확정·예외·미확정 구분, 디자인/개발 역할 분담, 동시 작업 및 인계 방법과 복사할 시작 요청문을 확인합니다. AGENTS.md의 자동 적용을 가정하지 말고 실제 문서 본문을 읽게 합니다.

## 시작 순서

1. [공통 작업 규칙](AGENTS.md)을 읽습니다.
2. [현재 Figma 링크와 서체 기준](docs/design-system.md#현재-figma-위치)을 확인합니다. [디자인 시스템 기준](docs/design-system.md)의 필요한 입력란을 채웁니다.
작업 전에 [컬러 기준과 변경 확인](docs/colors.md)을 읽고, 실제 Figma 변수의 변경 여부를 대조합니다.

3. [컴포넌트 목차](docs/components.md)로 작업 대상을 찾습니다.
4. 아래 작업 절차를 선택하고 [작업 요청 양식](tasks/TEMPLATE.md)을 복사해 작성합니다.
5. [공통 검수표](docs/quality-checklist.md)를 통과한 범위를 확인하고 완료·미완료·임시 적용을 작업 기록에 남깁니다.

## 공유 원칙

Figma는 실제 디자인을 관리하고 이 저장소는 AI 작업 기준과 기록을 관리합니다. 저장소 작성만으로 Figma가 수정되거나 동기화되지 않습니다. 연결 도구의 읽기·쓰기 기능을 확인해야 합니다.
