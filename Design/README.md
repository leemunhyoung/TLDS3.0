# 더 라운지 3.0 디자인팀 AI 하네스

버전: v0.4 · 2026-11-05 · 상태: 컬러 기준 v1 및 작업 전 변경 확인 반영 / 전체 컴포넌트 검수 별도

## 시작 순서

1. [공통 작업 규칙](AGENTS.md)을 읽습니다.
2. [현재 Figma 링크와 서체 기준](docs/design-system.md#현재-figma-위치)을 확인합니다. [디자인 시스템 기준](docs/design-system.md)의 필요한 입력란을 채웁니다.
작업 전에 [컬러 기준과 변경 확인](docs/colors.md)을 읽고, 실제 Figma 변수의 변경 여부를 대조합니다.

3. [컴포넌트 목차](docs/components.md)로 작업 대상을 찾습니다.
4. 아래 작업 절차를 선택하고 [작업 요청 양식](tasks/TEMPLATE.md)을 복사해 작성합니다.
5. [공통 검수표](docs/quality-checklist.md)를 통과한 범위를 확인하고 완료·미완료·임시 적용을 작업 기록에 남깁니다.

## 작업 절차

- [메인시안에 맞춘 Shadcn 수정](workflows/01-shadcn-update.md)
- [화면설계서 기반 서브페이지 제작](workflows/02-subpage-design.md)
- [고객 수정사항 반영](workflows/03-client-revision.md)

## 폴드폰 대응

[폴드폰 대응 기준](docs/foldable.md): 적용 예상 페이지는 제휴카드 페이지·마이페이지·사용처 페이지입니다. 동일 데이터로 배치만 조정하고, 접으면 현재 APP 레이아웃에서 보고 있던 콘텐츠와 상태를 유지합니다. 전환 너비·세부 영역 크기는 추후 협의합니다.

## 공유 원칙

Figma는 실제 디자인을 관리하고 이 저장소는 AI 작업 기준과 기록을 관리합니다. 저장소 작성만으로 Figma가 수정되거나 동기화되지 않습니다. 연결 도구의 읽기·쓰기 기능을 확인해야 합니다.
